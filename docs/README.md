# Documentation

The site uses Astro Starlight, with reference pages generated by griffe and internal links validated by Starlight Links Validator. Its Node dependencies are isolated from the published Python package; its Python dependencies are in `requirements.txt`.

Use Python 3.10 or newer, Node.js 24, and pnpm 10.34.2 (`npx -y pnpm@10.34.2` runs the pinned version without a global install). From the repository root:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e ".[test]" -r docs/requirements.txt
pnpm --dir docs install --frozen-lockfile
pnpm --dir docs generate
pnpm --dir docs dev
```

Keep the virtual environment active: the `package.json` scripts call `python3`, and without it they fail with `ModuleNotFoundError: griffe`.

Validate and build:

```sh
pnpm --dir docs check
pnpm --dir docs build
pnpm --dir docs preview
python -m pytest docs/scripts/tests
```

Authored pages live in `src/content/docs/`. The `api/` and `schema/` directories there are generated from the installed `TikTokLive` and `TikTokLiveProto` packages on every build; they are ignored by Git. Do not edit the generated Markdown; change the docstring at the source declaration instead.

`check` runs `scripts/check_content.py`, which compares the pages with the code in nine sections (events, catalog, client, web-defaults, routes, env, discord, readme, examples) and type-checks every Python example with mypy. `generate` runs `scripts/gen_api.py`. `build` runs both, then `astro build`, which validates links and builds the search index.

Facts come from the library source first, then the README, then the retired Sphinx pages in Git history (`git show 884489f:docs/src/index.rst`). Python fences must be complete modules that type-check, shell commands use `sh` fences, pages carry no Discord links, and links to Euler Stream are plain Markdown links. See the site's contributing page for the full rules.

## Hosting

The site is served from Cloudflare Workers static assets at <https://ttl.docs.isaackogan.com/>. `wrangler.jsonc` in this directory declares the asset directory and the custom domain for the `tiktoklive-docs` Worker; there is no Worker script. The GitHub workflow validates every pull request, runs the SEO gate (`scripts/seo/verify_seo.py docs/dist`), and on pushes to `master` deploys when the repository has the `CLOUDFLARE_API_TOKEN` secret; the deploy also needs `CLOUDFLARE_ACCOUNT_ID`. The same run publishes a redirect shell, generated by `scripts/gen_redirects.py`, to the old GitHub Pages site so its URLs land on the new pages.

To deploy from a checkout after the installs above:

```sh
pnpm --dir docs build
pnpm --dir docs run deploy:cloudflare
```

See [Cloudflare Workers hosting](src/content/docs/hosting.md) for the configuration, secrets, and verification steps. `DOCS_SITE` defaults to the custom domain and `DOCS_BASE` to `/`; neither needs to be set.
